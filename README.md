## Design

- **Color Palette**: Forest Green (#1B4332), Teal (#2A9D8F), Gold (#B08D57), Cream (#faf8f5)
- **Typography**: Cinzel (headings), Cormorant Garamond (body)
- **Aesthetic**: Art Deco with 2px borders and corner accents
- **Responsive**: Mobile-first design, optimized for all screen sizes

## Deployment

This website is deployed on **Cloudflare Pages** at **functionallyfitness.com**.

### Deploy Instructions

1. Ensure all image files are present in the `images/` folder
2. Commit all changes to your Git repository
3. Push to GitHub: `git push origin main`
4. Cloudflare Pages will automatically deploy the changes

### Images Required

Before deployment, add these images to the `images/` folder:
- `logo.png` - Functionally Fitness logo (transparent PNG recommended)
- `pexels-man-1868632_1920.jpg` - Tyler Smith portrait photo
- `stevepb-dumbbells-2465478_1920.jpg` - Dumbbells/In-Person training photo
- `sushil-ghimire-5UbIqV58CW8-unsplash.jpg` - Online coaching reference photo
- `pexels-adult-1850925_1920.jpg` - Hybrid training photo

## Development

No build step required. This is a static HTML/CSS website that works directly in any modern browser.

### Local Testing

1. Open `index.html` in your browser
2. All interactive links are functional
3. Test responsive design by resizing the browser window
